# Historical profile-window acceptance preview

This local generated studio tests the existing Rust selector with five players
and three numerical requests: exact2024–25, exact2025–26, and latest supplied
through2025–26. It is not the live application or a current2026–27 dataset.
Documentary identity retains its own evidence date and is not rewound by this
numerical selector. Capability grades remain unrated.

Exact missing data renders an unavailable panel without an older statistical
sheet. An explicit action requests latest available instead. A source-level
missing row does not establish that a player had no games or lacked skill.
The shared compact front places selection status immediately after scope in
both browser and native templates. Finishing's shared Rust readout states that
prior seasons are pooled under a constant multiplier: updating the estimate
does not test time-varying ability. No math, ratings or simulation parameters change.

## Replay

wasm-bindgen glue. Supply the retained catalog/package files, source-bound
numerical history with optional research, and documentary catalog. No network
acquisition is performed. The projector defaults to owned public assets and
`target/compact-sheet/inputs/pkg-finishing`; override with
`ICELINES_WINDOW_ASSETS` and `ICELINES_WINDOW_WASM`.

```powershell
node icelines-browser/node_modules/typescript/bin/tsc --project icelines-browser/tsconfig.json
$env:ICELINES_PROFILE_FIXTURES="$PWD/target/compact-sheet/profile-windows/fixtures.json"
node icelines-browser/e2e/rinkcraft-project-windows.mjs
node icelines-browser/e2e/rinkcraft-profile-windows.mjs
```

player/window shell around rendered static sheets,15-selection verification,
desktop/mobile screenshots, and10 one-page Letter PDFs. Dossier disclosures work;
serialized sheets do not recreate the full application's event handlers. This
acceptance sample intentionally expects one unavailable exact Barkov request
and one labeled older fallback; it is a frozen fixture contract, not a claim
about every source's2025–26 coverage.
