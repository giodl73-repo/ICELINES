# Attributes first with inspectable evidence — CHG-137

WP-RINKCRAFT-13 / IF-RINKCRAFT-NUMBERS-001. Research authority: Rinkcraft decision
0017 and attribute evidence protocol 0.1. No numerical/archive/class-data changes.

Optional `EvidenceFacet.explanation` has question, ordered related metric keys
and limit. `EvidenceCard.feature_context` defaults empty for legacy inputs and
contains declared authored attribute keys, relationship/note and unchanged
Measurement objects. Shared Rust owns the fixed definitions/bindings. No name-
based feature inference, composite score, class inference or statistical validity.
All related measurements retain their actual period, situation, formulas, units,
reference hashes and source custody. Distinguish conversion residual from shooting
percentage and environment from execution quality.

fixed-order facets above methods and history; each supports a closed evidence
expander, original components/reference, explicit limits and source/peer details.
Feature readouts use supplied context only for existing authored stat links.
Unmatched features remain explicit. Legacy profiles and optional-asset behavior
continue. Source-selection and full-window assessment rules remain unchanged.

profiles; per-facet and feature bindings; missing transport evidence; desktop
attributes within first screen; legacy/no-JS/offline/mobile and existing focused
