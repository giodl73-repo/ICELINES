# Explicit card comparisons with dated class identities — CHG-139

WP-RINKCRAFT-15 / existing Rinkcraft profile and numerical interfaces. Research
authority: Rinkcraft decision 0019; prior source/attribute/contrast protocols stand.

Native card HTML and browser profile enrichment offer available counterparts from
the actual numerical source year and same position group, excluding self. Require
an explicit choice; carry left/right IDs and year into existing comparison routes.
No class, similarity or performance ordering of candidate players. Native has a
no-JS GET form and separate same-season browse link. Browser dispatch adds optional
`right_id`; older direct renderer callers without choice metadata remain compatible.
Existing shared comparison checks still govern eligibility and missing requests.

Both comparison views add optional presentation-only documentary identities using
existing shared CharacterCatalog/character_sheet selection for the comparison year.
Show primary/secondary classes, analogy, specialty/purpose, source/evidence/assessment
dates and catalog hash. Historical unknowns are Unscouted; absent/invalid class
catalog is unavailable. Numeric comparison remains usable in either case; atlas
absence no longer hides numeric controls. Version/generation guards suppress stale
class reads and abandoned card handoffs. Optional class-source failures also preserve primary numerical cards, with
availability status distinct from a valid catalog without an eligible dossier.
No new worker operation or public numeric API/core schema. Browser UI-only choice metadata is not a model field.

No source/class/measurement/rank, source-selection, summary or history-policy changes.
No empirical role/skill/style, similarity, chemistry or classification inference.
Acceptance: explicit IDs/year from all-position cards, source-scoped picker contents,
older fallback, historical unknowns, class provenance, optional failures, stale-read
race, legacy/no-JS/offline/mobile/theme behavior and existing numerical regressions.
Evidence: `docs/rinkcraft-card-comparison-validation-2026-11-09.md`.
